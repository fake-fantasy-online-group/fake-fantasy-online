# Mobile skill book and native panels

Mobile keeps the original inventory, character and Win05 panel artwork, layout and authored tooltip content. It only changes input and uniformly fits the native panel bounds inside the safe area. Desktop layout, pointer behavior and tooltip renderer remain unchanged.

- The bag uses its original 423×501 frame, all 100 cells (10×10), four original tabs, money/weight row, sort button and native split dialog. There is no mobile-only 5×4 page, details column or replacement split screen.
- Character equipment retains its original doll, slots, attribute controls, vertical tabs and title/task flyouts. Win05 panels retain their original frame and content, including the pet side panel. Dragged windows are clamped inside the safe area.
- Tap a bag/equipment/combat/life-skill icon to keep its original tooltip open. Tap elsewhere to dismiss or select another item. Original text, colors, wrapping and frame are retained; equipment comparisons remain separate cards. Long ordinary/skill cards can be dragged to read the remaining original rows.
- Hold a bag/equipment/combat-skill icon for 0.5 seconds to expose its actions. A hold never uses/equips/learns/binds automatically. Dragging, a second touch, cancellation, lost contact, focus/pause, receipts, tab changes or safe-area changes cancel pending selection.
- Bag actions reuse the original picker chain, trade offer/withdrawal, cube/warehouse/wardrobe destinations, use/equip, lock/unlock, split and share paths. The selected live item is re-resolved at execution. An incompatible active picker cannot fall through to use an unrelated item.
- The combat tree stays visible while a tooltip or action menu is open. Drag the original tree to scroll. Its original plus button can be tapped to learn/upgrade; the long-press action also uses the same eligibility and server request.
- “放入快捷栏” offers the original 30 hotbar entries as eight pages of four (two on the last page). Choosing a slot rechecks usability, replaces that original slot and uses the existing hotbar sync writer, without casting or learning. Equipped artifact skills use the same explicit chooser.
- Cancel/close/tab/window changes and interruptions never commit a pending binding. The original desktop click/drag and mouse-wheel behavior remains available.

Validation: with `Documentation/tools/activate-dotnet-test-toolchain.sh` sourced, run `Tests/Mobile/run-skill-binding-contract.sh`, `python3 Tests/Mobile/native-inventory-action-contract.py`, `python3 Tests/Mobile/original-panel-source-contract.py`, `Tests/Endgame/run-skill-tooltip-contract.sh`, and `python3 Tests/Endgame/run-additional-equipment-contract.py`. These compile actual native methods and adapters with deterministic boundary substitutes, including touch ownership/cancellation, uniform fitting, full tooltip drag reachability, comparison cards, action admission and hotbar replacement. Full Presentation compilation is also required. Managed contracts do not replace Unity rendering, device touch, or live-server acceptance.

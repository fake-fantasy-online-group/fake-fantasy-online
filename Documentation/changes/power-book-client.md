# 威能秘典客户端（2026-10-28）

## 交互

由任务取得的永久道具打开秘典，不设置背包顶部功能入口。保留范围（职业）、类型、部位三个筛选框，以及隐藏未获得复选框。列表列为威能、分类、数值范围；鼠标悬停显示记录的实际效果。点击已获得条目提取绑定卷轴；未获得条目可查看合法数值范围但不能提取。卷轴右键复用外形道具的装备目标选择，交由服务端决定装备或翅膀的承载资格。

`powerbook.list` 的可选 `rangeText` 为服务端生成的实际效果参数上下限，不是通用的 75%–100% 品质百分比。多参数按带含义的分行文本展示，列表行高按文本测量。纯功能性或旧服务端未提供范围时展示 `—`，不伪造 0–0。`description` 仅显示当前效果；客户端不解析文字计算伤害、不用通用正则掩盖真实限制。普通装备词缀/洗练的数值范围保持不变。

`powerbook.extract` / `powerbook.apply` 使用已有单次变更请求与精确 UID，重复点击、未取得道具、背包未同步、锁定道具及未获得记录不能绕过检查。原直接刻印入口和 `powerbook.imprint` 不恢复。

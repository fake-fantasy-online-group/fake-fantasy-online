# Two-affix and set activation blue

The wire quality number is not the affix count. One-affix equipment retains quality 2
and RGB 82/150/252. Two-affix equipment now uses quality 6 and RGB 105/223/223, the
same shared palette entry as text prefix U+0005 (activated set effects and existing
two-affix body text). Quality 5 remains dark gold. No packet structure changes.

`run-equipment-blue-contract.py` compiles the production native `UITip.Layout`
methods and diagnostic renderer with deterministic Unity/font substitutes. It checks
five set names across 0/2/4/6/8 pieces, gray/blue activation and palette parity.
Optional `.bin` arguments decode actual server 0x8006 payloads with the production
`PrivateServerInventoryCodec`, then use production `TooltipContent.QualityName`,
`Fmt` and `UITip.Layout`. Optional text arguments render actual server tooltip text.
Outputs are `<input>.rows.tsv` for offline preview, not Unity player screenshots.

Use FFO_MONO, FFO_CSC, FFO_FRAMEWORK_DIR and FFO_MANAGED_DIR (the output of
run-managed-compile.sh), plus the same Mono library environment as other contracts.

Inventory/equipment/store/stall/drop names/wash/chat consume the shared quality
palette. NPC purchase list 0x801c has no quality field: its existing white item names
remain white; blue body text is independent. No inference from arbitrary description
color tags is introduced. Slot backdrops/category icons are not equipment-quality
colors and are unchanged. Old clients do not know quality 6 and show white, so this
requires the matching client and server update.

The checked-in 338-byte fixture is synthetic, generated by server inventorySnapshot
then protocol.Encode: one one-affix and one two-affix item, plus an equipped quality-6
row. No player credentials or actual user inventory are included. The contract always
decodes this fixture. Old names containing U+0005 are deduplicated when quality 6 is
added, preserving existing no-quality name consumers. The original drop confirmation
rarity check excludes quality 6, preserving the old two-affix behavior; bound/fused/
stacked items and every other quality retain their previous confirmation conditions.

The cyan RGB 105/223/223 (#69DFDF) is the approved reference-image representative
color, not a claim to recover an original game constant. It replaces the rejected
previous direct-prefix RGB 86/196/255. Set headings use server-supplied equipment
text quality; the per-effect active/inactive markers remain U+0005/U+0002.
